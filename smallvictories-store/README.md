# Small Victories — Print Store

A standalone print store for [smallvictories.com.au](https://smallvictories.com.au/):
framed photographic prints, fulfilled through
[Format Framing](https://formatframing.com.au) (Melbourne), payments through Stripe.

It's a static site — no build step, no database. It works on any static host
(deploy to `smallvictories.com.au/store/`, or `store.smallvictories.com.au`).
Checkout runs on **Stripe Payment Links**, so no server is required. An optional
serverless checkout function is included if you ever want a cart.

```
smallvictories-store/
├── index.html / style.css / script.js   the storefront
├── success.html                         post-purchase page
├── config/
│   ├── prints.json                      YOUR photographs for sale ← edit this
│   ├── frames.json                      Format Framing colours/sizes/COSTS ← edit this
│   ├── store.config.json                markup, URLs, currency ← edit this
│   └── stripe.json                      generated by the setup script
├── lib/pricing.mjs                      cost × markup → retail price
├── scripts/stripe-setup.mjs             creates Stripe products/prices/payment links
└── api/checkout.js                      optional serverless checkout (Vercel)
```

## 1. Put in the real Format Framing prices

**The costs in `config/frames.json` are estimates** — Format Framing's site blocks
automated access, so I couldn't pull live prices. Open
[their Online Print and Frame page](https://formatframing.com.au/products/online-print-and-frame),
note the price for each set size you want to offer, and update `costFramedAud`
(then delete the `"estimate": true` flags and set `"costsAreEstimates": false`).

Frame colours (black / white / natural oak) are the same price at Format Framing,
so cost lives on the size, and colour is just a variant choice at checkout.

Adjust your margin in `config/store.config.json`:

- `markup: 2.0` — retail = cost × 2 (keystone). 2–3× is typical for editioned photographic prints.
- `roundUpTo: 5` — prices round up to the nearest $5.

Sanity-check the resulting price table without touching Stripe:

```sh
cd smallvictories-store
npm install
npm run stripe:dry-run
```

## 2. Add your photographs

Edit `config/prints.json` — one entry per print (slug, title, description, which
sizes it's offered in, portrait/landscape) — and drop the image files into
`assets/`. The three sample entries show the shape; delete them when done.

## 3. Connect Stripe

1. Create an account at [stripe.com](https://stripe.com) (choose Australia; prices are AUD).
2. Grab your **test** secret key from [dashboard.stripe.com/test/apikeys](https://dashboard.stripe.com/test/apikeys).
3. Run the setup script:

   ```sh
   STRIPE_SECRET_KEY=sk_test_... npm run stripe:setup
   ```

   For every active print × size it creates a Product, a Price, and a **Payment
   Link** that collects an AU shipping address, phone number, and the frame
   colour (dropdown). It writes the IDs and links to `config/stripe.json` —
   commit that file and the storefront's Buy buttons go live.

4. Test a purchase with card `4242 4242 4242 4242`.
5. When happy, activate your Stripe account and re-run with your live key
   (the `--live` flag is a deliberate safety catch):

   ```sh
   STRIPE_SECRET_KEY=sk_live_... npm run stripe:setup -- --live
   ```

Re-running is safe: it updates in place, deactivates old prices when amounts
change, and mints fresh payment links as needed.

## 4. Fulfilment (how an order becomes a framed print on a wall)

This is a dropship flow — Stripe takes the money, you place the order:

1. Turn on email notifications for successful payments:
   Stripe Dashboard → Settings → **Communication preferences**.
2. When an order lands you'll see the print, size, frame colour, quantity, and
   the customer's shipping address/phone in the payment details.
3. Order exactly that from Format Framing's site, shipped directly to the
   customer's address. Their prints are made and shipped in ~5 days, free AU delivery.

## Notes

- **GST**: if you're not GST-registered (under $75k turnover) don't charge it.
  If you are, enable Stripe Tax or set prices as GST-inclusive.
- **Success/cancel URLs** in `store.config.json` assume the store lives at
  `smallvictories.com.au/store/` — change them if you deploy elsewhere.
- **Optional serverless checkout** (`api/checkout.js`): deploy this folder to
  Vercel, set `STRIPE_SECRET_KEY` and `ALLOWED_ORIGIN` env vars, then set
  `checkoutEndpoint` in `store.config.json` to `https://<your-app>.vercel.app/api/checkout`.
  Benefit: the frame colour picked on the page is passed straight into checkout
  metadata instead of the customer re-selecting it in the Payment Link dropdown.
- Never commit secret keys. Only the publishable data in `config/stripe.json`
  (price IDs and public payment-link URLs) belongs in the repo.
- Local preview: `npm run dev` → http://localhost:4002
